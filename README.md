# Experiment Zone #

A sandbox repository dedicated to testing code, experimenting with algorithms, and trying out new Python features and script patterns.

---

## Project Overview ##

**Experiment Zone** serves as a practical testing ground for implementing core algorithms, script utilities, and programming logic. 

Currently, the primary focus includes:
* **Cipher Algorithms:** Hands-on implementations of classic encryption and decryption techniques, such as the **Caesar Cipher**.
* **Python Utilities:** Code snippets for string manipulation, data validation, and custom function design.

---

## Features ##

* **Caesar Cipher Implementation:** Easily encrypt and decrypt messages with custom integer shifts.
* **Input Validation:** Built-in checks for numeric data types, range constraints, and parameter handling.
* **Modular Code Structure:** Cleanly structured utility functions (`encrypt`, `decrypt`, `apply_discount`) designed for reuse and extension.
